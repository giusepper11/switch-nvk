## Why

FG-2 remains `BLOCKED` after the valid two-root/two-QMD experiment changed the failure boundary: seeds 5 and 42 were consumed exactly, then the first revisit of root A at iteration 3 and every later launch retained seed-42 output. The subsequent QMD v0.6 `INVALIDATE_SHADER_CONSTANT_CACHE` bit-255 experiment was `specific_qmd_shader_constant_cache_invalidate_insufficient`, so the next smallest discriminator is whether delaying the first compute-root GPU-VA revisit by one dispatch delays stale-state onset by exactly one iteration.

## What Changes

- Add one same-source paired 64-iteration FG-2 experiment using identical three-root/four-QMD reservation, initialization, diagnostics, backing, ownership, lifetime, and teardown in both arms.
- Select roots A/B/A/B... in the control and A/B/C/A/B/C... in the variant, while both arms select QMDs X/Y/Z/W/X... . This places the control's first root revisit at iteration 3, the variant's at iteration 4, and the first QMD revisit at iteration 5.
- Preserve the retained allocation positions where actual reconstruction permits by appending QMD Z, QMD W, and root C after root A, QMD X, QMD Y, and root B. Require actual offset, alignment, GPU-VA, capacity, one-BO/NvMap, lifetime, and later-upload-displacement proof; a second backing allocation stops causal review.
- Add strict mutually exclusive control/variant selectors, reject malformed values and combinations with every prior experiment selector before device work, and preserve ordinary execution when the new selectors are absent.
- Extend the existing bounded root/QMD diagnostics to compute reuse distance and first-revisit state from actual dispatched GPU VAs; prove exact root copies, complete QMD equality outside generated-layout root-address fields, decoded root selection, mapped-QMD-to-direct-`PCAS` equality, ordering, oracle results, fault state, and teardown for all 64 records.
- Freeze shaders, generated bytes, seed formula, root semantic contents, QMD cache bits (including `INVALIDATE_SHADER_CONSTANT_CACHE=FALSE`), resources, barriers, command-buffer lifecycle, GPU methods, dispatch, submission, waits, cache behavior, synchronization, readback, and oracle. Do not combine cache, membar, timing, backing, allocator, FG-3, or FG-4 interventions.
- Gate the variant on a control that exactly consumes seeds 5 and 42, first fails on root A's iteration-3 revisit while QMD Z is new, and retains pixel `0xf5031a17` / checksum `0x0daf4ac5` without an unexplained fault.
- Define only four outcomes: `root_address_reuse_distance_hypothesis_supported_experiment_only`, `specific_root_address_reuse_distance_change_insufficient`, `behavior_changed_unresolved`, and `inconclusive`. The supported outcome requires the variant to consume seed 79 at iteration 3 and first retain seed-79 state on root A's iteration-4 revisit while QMD W is new.
- Retain complete host/provenance evidence and, only after the control gate, complete paired real-Tegra logs and narrow findings. Keep FG-2 `BLOCKED` for every outcome; experimental support still requires a separate remediation decision and ordinary-path hardware acceptance change.

The experiment tests only a behavioral root-revisit boundary. Public GM20B/QMD source evidence distinguishes SKED and shader-constant-cache invalidation controls but does not identify the relevant root-state key, lifetime, VA-versus-physical identity, or replacement policy and is not `PROVEN_HW`.
